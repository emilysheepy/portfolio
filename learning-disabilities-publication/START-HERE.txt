GITHUB PAGES

The website files were built for this path:
  /portfolio/learning-disabilities-publication/

If your portfolio repository publishes its root directory through GitHub
Pages, put the CONTENTS of website/ into a folder named:
  learning-disabilities-publication/

Keep index.html, assets/, images/ and favicon.svg together in that folder.
Do not upload the ZIP itself as the website. Keep source/ and internal
review documentation outside the publicly served website directory.

If the repository uses a different publishing directory or an Actions
workflow, include these built files in that directory or its Pages output.
This package does not change or configure your deployment workflow.

For a different URL path, rebuild from source with the matching BASE_PATH.
The existing application router requires the correct path.

BUILD FROM SOURCE

Requires Node.js 22 or later and pnpm.
From source/:

  pnpm install --no-frozen-lockfile
  PORT=22535 BASE_PATH=/portfolio/learning-disabilities-publication/ pnpm --filter @workspace/learning-disabilities-publication run build

The build output is:
  artifacts/learning-disabilities-publication/dist/public/

The lockfile retains the original workspace's dependency records. A
non-frozen install allows pnpm to reconcile the smaller exported workspace.
Use the publication-specific command above, not the original workspace's
top-level build command, which also expects applications excluded here.

To preview locally:

  PORT=22535 BASE_PATH=/portfolio/learning-disabilities-publication/ pnpm --filter @workspace/learning-disabilities-publication run dev

Then open:
  http://localhost:22535/portfolio/learning-disabilities-publication/
