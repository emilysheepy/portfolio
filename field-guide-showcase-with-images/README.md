# Field Guide Learning showcase
Open index.html in a browser. No build step. Upload index.html, data.js and assets/ to GitHub Pages.

Edit data.js to add, remove or reorder demos. Copy an existing object and change its unique id, title, category, description and URL. Categories are generated automatically. Save screenshots in assets/ and set thumbnail to e.g. assets/quick-check.webp; add thumbnailAlt if the image communicates additional information. Empty thumbnails show an explicit placeholder. Optional launchLabel, secondaryUrl and secondaryLabel fields provide alternate versions on one card. Archivo loads from Google Fonts with Arial fallback. All demos open in a separate tab.

The wordmark is provisional; palette and Archivo typography follow the supplied brand document; replace them with official brand assets when available. Only include materials approved for public disclosure. Public GitHub Pages and data.js are not access controlled. Accessibility-oriented implementation, not a certified audit.
